# 🎮 Number Guessing Game

A simple Python guessing game where players try to find a randomly generated number with hints, scoring system, and game history features.

## 📌 About Project

Number Guessing Game is a beginner-friendly Python project that challenges players to guess a hidden random number between 1 and 10. The game provides hints whether the guess is too high or too low and calculates the player's score based on the number of attempts.

This project is created to practice basic Python programming concepts such as variables, functions, loops, conditional statements, error handling, and random number generation.

## ✨ Features

- 🎲 Random number generation
- 🔢 Guess numbers from 1 to 10
- ⬆️ Hint system (too high / too low)
- ⭐ Score calculation system
- 🔄 Replay game option
- 📜 Game history tracking
- ⚠️ Input validation for invalid entries

## 🛠️ Technologies

- Python 3
- Random Module

```

```bash
cd number-guessing-game
```

3. Run the program:

```bash
python tebak_angka.py
```

## 🎮 How to Play

1. Choose the **Start Game** menu.
2. Enter a number between 1 and 10.
3. Follow the hints:
   - "Too small" means your guess is below the correct number.
   - "Too big" means your guess is above the correct number.
4. Try to get the highest score by guessing with fewer attempts.
